# Reinklang

Eine relativ simple Klaviatur im Browser. Es können verschiedene Stimmungen gesetzt werden,
und der Grundton der Stimmung kann frei gewählt werden.

**Ausprobieren:** https://einthilo.github.io/reinklang/

## Bedienung in Kürze

- **Hauptklaviatur** (unten): spielen, auch mit mehreren Fingern gleichzeitig.
- **Grundton-Klaviatur** (oben): ein Tipp wählt den Grundton, auf den sich die gewählte Stimmung bezieht.
  - **⇤** – der jeweils tiefste klingende Ton wird zum Grundton.
  - **1.** – der erste Ton, der angeschlagen wird, während nichts klingt, wird zum Grundton.
  - **tuning off** – zurück zur gleichstufigen Stimmung.
  - Die kleine Zahl auf den Tasten zeigt die Abweichung von der gleichstufigen Stimmung in Cent.
- **Sustain / Release:** Sustain hält Töne (tippen = an/aus, gedrückt halten = wie ein Pedal),
  Release beendet gehaltene Töne.
- **Stimmung, Instrument, Stimmton (Hz), Transposition** und Tastenbereich lassen sich einstellen.

Beim Öffnen einmal auf die Seite tippen – erst danach darf der Browser Klang abspielen.

## Geräte und Browser

Gedacht vor allem für Touchscreens (Handy, Tablet), läuft aber auch am Rechner.
Getestet mit aktuellem Chrome und Firefox, vor allem unter Android. iOS ist noch kaum getestet.
Die Seite speichert nichts und sendet nichts.
